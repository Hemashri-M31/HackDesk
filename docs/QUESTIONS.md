# 10 real questions my user will ask

Write them the way your user would type them. At least 3 must need more than one page to answer, and at least 1 must be a question your documents cannot answer. The references below are intended Next.js documentation sources; page numbers will be added when the dataset is collected.

| 2 | What is the difference between page.tsx, layout.tsx, and template.tsx in Next.js? | [Pages and Layouts](https://nextjs.org/docs/app/getting-started/layouts-and-pages), Templates | Yes |
| 3 | How does caching work in Next.js, and how can I revalidate cached data when it changes? | Caching, `revalidatePath`, `revalidateTag` | Yes |
| 4 | Why is my API request returning stale data in Next.js, and how can I refresh it without rebuilding the entire application? | Caching, Data Fetching, Revalidating Data | Yes |
| 5 | What is the difference between Server Components and Client Components, and when should I use the "use client" directive? | Server Components, Client Components | Yes |
| 6 | Why am I getting the error "You're importing a component that needs useState. It only works in a Client Component"? | Server and Client Components | No |
| 7 | How can I optimize images in Next.js to improve page loading speed? | [Image component](https://nextjs.org/docs/app/api-reference/components/image) | No |
